# 面试题库助手（Java 后端 / Agent）

本地单用户题库，包含 40 道带答案的通用题。首次打开须验证并配置自己的 DeepSeek API Key；调用 AI 会消耗你自己的 API 额度。简历可跳过，跳过后仍可练习通用题并使用通用 AI 出题。个人项目深挖题需先确认简历事实。

刷题页可以展开“AI 出题方向”，选择高频八股、后端场景设计、Agent 八股、Agent 场景设计、项目深挖，并分别设置相对权重；折叠状态会保留。设置页可调整个人面经、网络面经、AI 模拟的来源比例，技术面与 HR 面共用。来源比例设为 0 时，该来源的到期复习题也会暂停；当天未刷完的到期题会继续保留。

## 安装与使用

macOS：下载与你的 Mac 芯片匹配的 Apple Silicon 或 Intel 构建中的 `面试题库助手.app`，双击打开。首次运行若 macOS 阻止未签名应用，在系统设置的“隐私与安全性”中允许打开。Windows：下载 Windows 构建产物中的 `面试题库助手` 文件夹，双击其中的 `面试题库助手.exe`。请保留整个文件夹。两平台都无需另装 Python；程序仅在 `127.0.0.1` 的随机可用端口启动，浏览器自动打开页面，在设置中点击“退出应用”关闭服务。

API Key 存于操作系统凭据库。题库、练习记录、已确认简历事实等存于当前用户的系统应用数据目录（`InterviewQuestionBankOpen`）。安装目录不保存用户数据库。AI 整理简历前会显示要发送的文字；上传文件只在内存中提取，不持久保存。请自行复核自动去除联系方式后的文字，再点击“AI 整理”。扫描版 PDF 需先自行转成可复制文字。

简历事实以普通文字显示和保存，可在设置中直接修改。若要启用项目深挖，请将每个项目名称单独写成“项目：名称”一行。旧版 JSON 格式事实会自动转换为文字。

## 备份和升级

在“设置 → 完整数据备份”导出 JSON 文件。文件包含题目、答案、已确认简历、练习和复习记录、AI 讨论与导入预览；不含 API Key。导入会先校验格式及数据关联，自动在本机 `backups/` 保存目标题库的导入前数据库，再用备份文件整库覆盖。升级时替换应用包或程序文件夹，保留用户数据目录即可。API Key 在系统凭据库中单独管理；不要把数据库或含简历的备份上传到公开仓库。

## 从源代码开发

使用 Python 3.11 或 3.12：`python -m venv .venv`，安装 `pip install -r requirements.txt pyinstaller httpx`。设定 `INTERVIEW_DATA_DIR` 为独立测试目录，再运行 `python launcher.py`。执行 `python -m unittest discover -s tests` 验证，`python packaging/build.py` 在当前系统生成双击程序。Windows 包必须在 Windows 上构建，macOS 包必须在 macOS 上构建。推送 `v*` 标签时，GitHub Actions 会构建三个平台的安装包并发布 Release。

## 隐私与范围

代码和安装包不附带任何用户数据库、简历、飞书数据或私人 API Key。简历仅在用户主动点击整理时发往本人配置的 DeepSeek；通用题不需简历。首版不支持扫描版 PDF OCR、多人共享、飞书同步和手机安装。
